Scoring System
2 changes
Tuned
Full paytable rebalance — all hand values multiplied ×10
All base hand scores have been scaled up by 10×. This creates more scoring headroom for multipliers, bonuses, and future Vegas hand effects without hitting the score ceiling too quickly.
Natural Royal: 1,000→10,000
Straight Flush: 40→400
One Pair: 1→10
New
Vegas Scoring Mode
An optional alternate scoring layer that adds 11 specialty hands on top of standard poker scoring. Vegas hands reward specific card combinations with bonus points or game-altering effects. Includes a full visual re-theme of the UI when active — dark casino aesthetic with neon accents, animated title, and casino felt board.
Specialty hands include: Steel Wheel (500 pts), Baba's Quads (444 pts), Orient Express (×8 final score multiplier), Poker Brat (17 pts + ×2 future multiplier), Texas Dolly (102 pts), Broadway / Wheel (88 pts each), Ryan's Riches (94 pts), Dead Man's Hand (instant escape, score reset to 0), PaiGow! and Low Ball (44 pts each).

UI & Layout
5 changes
Changed
Header completely redesigned
The old single-row header (title + controls side by side) has been replaced with a two-bar layout. The title now sits in its own full-width bar above a dedicated controls bar, which is divided into "In-Game" options (New, Sound, Deck, Rules) and "Out-of-Game" setup (Mode, Difficulty, Scoring). Clearer hierarchy, less visual crowding.
New
Active Buffs Tray
A persistent tray below the header displays any active game buffs as animated chips. Currently used by Vegas hands that apply ongoing effects (e.g. Poker Brat's ×2 score multiplier, Orient Express multiplier). Displays "No active buffs" when empty.
New
Interaction State Chip
A small status indicator sits next to the message box showing the current game interaction state: Open (player can act), Waiting (awaiting input), or Locked (no action available). Helps players understand what the game expects at a glance.
New
Collapsible Scoring Reference Tables
The Options panel now contains expandable scoring tables for both Regular hands and Vegas hands, so players can reference point values without leaving the game. Vegas table is only shown when Vegas Scoring is active.
Changed
Hand Result area updated
The hand result display now supports a Recall button and proper flex layout for the hand name, score badge, and action. Specialty hands get a distinct blue glow styling to visually differentiate them from standard hands.
🎲
Game Modes
2 changes
New
Vegas Choice Banner
When a hand qualifies for both a standard score and a Vegas specialty score, a contextual banner appears on the board asking the player to choose which scoring to apply. Supports strategic decision-making — e.g. a hand that scores as both a Full House (80 pts) and Texas Dolly (102 pts) can be player-directed.
Changed
Scoring Toggle moved to Options: Out-of-Game
Vegas Scoring (previously called Specialty Hands) is now grouped with Mode and Difficulty as a setup option, not an in-game toggle. It is locked once a game is in progress, consistent with Mode and Difficulty behavior.
